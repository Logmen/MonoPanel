# Живое демо

https://demo.monopanel.app — настоящий Web UI и API панели, которые каждый посетитель
открывает в своём контейнере Cloudflare. За панелью стоит не сервер, а имитация: пакеты,
службы, unix-аккаунты и конфиги живут в памяти, файлы сайтов — настоящие, внутри
контейнера. Ничего не исполняется на хосте, выхода в интернет у контейнера нет.

## Как устроено

- **Панель** — обычный бинарник, собранный с тегом `demo` (`go build -tags demo`): только в
  такой сборке есть скрытая команда `monopanel demo`, в релизы имитация не попадает.
  `internal/demo` — агент-имитация (пакеты и версии как на Ubuntu 24.04, службы, модули
  PHP, crontab, restic, mysql), файловый менеджер работает через штатный `fsop` над
  каталогом аккаунта.
- **Образ** (`Dockerfile`, контекст — корень репозитория): Web UI, панель с тегом `demo`,
  Ubuntu 24.04. Уже при сборке `monopanel demo prepare` заводит администратора `demo`,
  ставит стек, аккаунты, сайты, Valkey, базы, cron, почту, firewall и бэкап через
  настоящий API — как `scripts/screenshots/seed.sh` — и рисует сутки графиков, так что
  контейнер отвечает сразу после старта.
- **Контейнер** запускает `monopanel demo serve`: API на 127.0.0.1:8443 (для веб-консоли) и
  обычный HTTP на :8080 для воркера. Этот вход сам подставляет токен демо-администратора,
  а то, что без интернета работать не может (обновление панели, Let's Encrypt, установка
  CMS, Roundcube, composer и sphinx, переезд), отвечает «недоступно в демо».
- **Воркер** (`src/worker.js`): страница с кнопкой на русском или английском (правило
  языков то же, что у Web UI), по кнопке — новая сессия и свой контейнер, дальше все
  запросы сессии идут в него, а поверх HTML панели — плашка «это демо». Контейнер засыпает
  после 15 минут без запросов и живёт не дольше часа; `/end` закрывает демо сразу. Не
  больше пяти запусков в минуту с адреса и не больше `max_instances` контейнеров
  одновременно — дальше посетитель видит «попробуйте через пару минут».

Проверка без Cloudflare: `internal/demo` покрыт тестом (готовит демо и поднимает его), а
целиком — `make demo` и

```bash
./dist/monopanel-demo demo prepare --dir /tmp/mpd --www /tmp/mpd-www --panel 127.0.0.1:18443
./dist/monopanel-demo demo serve --dir /tmp/mpd --www /tmp/mpd-www --panel 127.0.0.1:18443 --listen 127.0.0.1:8090
```

— панель на http://127.0.0.1:8090 без входа. С Docker: `docker build -f demo/Dockerfile -t mp-demo .`
из корня и `docker run -p 8090:8080 mp-demo`.

## Публикация

Отдельный проект Workers Builds, подключённый к тому же репозиторию:

| Поле | Значение |
|---|---|
| Имя проекта | `monopanel-demo` (совпадает с `name` в `wrangler.jsonc`) |
| Root directory | `demo` |
| Build command | `npm run build` |
| Deploy command | `npx wrangler deploy` — собирает образ в окружении Workers Builds и выкатывает контейнеры |
| Build watch paths | include `demo/*`, `internal/*`, `cmd/*`, `web/*`, `templates/*`, `go.mod`, `go.sum`, `site/public/*` |

Нужен тариф Workers Paid (контейнеры). Адрес `demo.monopanel.app` воркер заводит сам
(`routes` с `custom_domain`), зона `monopanel.app` — в том же аккаунте. Первый деплой
занимает несколько минут: Cloudflare готовит образ.

Стоимость: тариф `lite` (1/16 vCPU, 256 МБ), в $5 Workers Paid входит около ста часов
работы таких контейнеров в месяц, дальше — порядка $0.003 за час.
